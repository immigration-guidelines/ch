# Immigration guidance: Switzerland

Published guidance that the authorities of Switzerland issue to the officials who decide immigration cases, collected in November 2026.

- **Guidance:** 332 files in this folder. `index.tsv` lists each file with its title, date and source address.
- **Country-of-origin reports:** 151 files in `coi/`, with their own `coi/index.tsv`.
- The files are unmodified copies of what the source published. Where a source refused automated access, copies come from a public web archive; the index says which.
- What is missing, and how to obtain it, is described in [MISSING.md](https://github.com/immigration-guidelines/.github/blob/main/MISSING.md), in the repository that also holds the download scripts. Other jurisdictions are listed on the [organisation page](https://github.com/immigration-guidelines).

**Cantons.** `cantons/` holds what the cantonal migration and naturalisation authorities publish, 75 files from 11 cantons, with its own `cantons/index.tsv`. Only Zürich publishes a full set of migration-office directives; elsewhere it is mostly naturalisation handbooks for communes or isolated papers. `cantons/NOTES.txt` has a line for each of the 26 cantons saying what was checked, and `cantons/not-obtained.tsv` lists what is known to exist but could not be fetched.

The documents remain the work of the authorities that published them.
